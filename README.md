# 入金消込アプリ

ローカル完結型の経理向け入金消込デスクトップアプリケーション

## 概要

請求書CSVと入金CSVを読み込み、金額照合を行うElectron製デスクトップアプリです。
クラウド連携不要で、全てローカルで完結します。

## 主な機能

- **請求書CSVインポート**: 請求書データをCSVから読み込み
- **入金CSVインポート**: 入金データをCSVから読み込み
- **照合実行**: 請求額と入金額を自動照合
- **判定表示**: 完全一致(〇) / ほぼ一致(△) / 未一致を表示
- **ローカル保存**: データはローカルJSONファイルに保存

## 技術スタック

- **Electron**: デスクトップアプリケーションフレームワーク
- **TypeScript**: 型安全な開発
- **Node.js**: バックエンド処理
- **csv-parser**: CSV読み込み
- **electron-builder**: Windowsインストーラ生成

## セットアップ

### 必要環境

- Node.js 18以上
- npm

### インストール

```bash
# 依存関係のインストール
npm install
```

## 使い方

### 開発モード

```bash
# TypeScriptをビルドしてアプリを起動
npm start
```

### ビルド

```bash
# TypeScriptのビルドのみ
npm run build

# Windowsインストーラを生成
npm run dist
```

インストーラは `release` ディレクトリに生成されます。

## クイックスタート

サンプルCSVファイルを使用して動作確認できます：

1. アプリを起動: `npm start`
2. 「請求書CSV取込」ボタンをクリックして `data/sample_invoices.csv` を選択
3. 「入金CSV取込」ボタンをクリックして `data/sample_payments.csv` を選択
4. 「照合実行」ボタンをクリック
5. 照合結果が表示されます

サンプルデータでは以下の結果が確認できます：
- 完全一致(〇): 3件
- ほぼ一致(△): 1件（差額500円）
- 未一致: 1件（差額1,000円）

## CSVフォーマット

### 請求書CSV

以下のカラムが必要です：

| カラム名 | 説明 | 必須 |
|---------|------|------|
| 取引先コード | 取引先の識別コード | ○ |
| 法人名 | 法人名 | ○ |
| 施設名 | 施設名 | ○ |
| 請求額 | 請求金額（数値） | ○ |
| 入金予定日 | 入金予定日 | - |
| 入金日 | 実際の入金日 | - |
| 入金額 | 実際の入金額 | - |
| 手数料 | 振込手数料 | - |

**注意**: 請求額が0または空欄の行は自動的に除外されます。

### 入金CSV

以下のカラムが必要です：

| カラム名 | 説明 | 必須 |
|---------|------|------|
| 入金日 | 入金日 | ○ |
| 入金額 | 入金金額（数値） | ○ |
| 入金元口座名義 | 振込元の口座名義 | ○ |
| 銀行 | 銀行名 | ○ |

## 照合ロジック

- **完全一致 (〇)**: 請求額と入金額が完全に一致
- **ほぼ一致 (△)**: 差額が1,000円以内
- **未一致**: 上記以外

## データ保存

データは以下の場所に保存されます：

- **Windows**: `C:\Users\<ユーザー名>\AppData\Roaming\payment-matcher`
- **macOS**: `~/Library/Application Support/payment-matcher`
- **Linux**: `~/.config/payment-matcher`

保存ファイル：
- `invoices.json`: 請求書データ
- `payments.json`: 入金データ
